Jev: An AI That Decides, Not Writes

A customer writes: “I have contacted you three times, and I am still waiting.” Your shop code can count items in a cart. It cannot read the feeling in that sentence. Jev is built for that second job.

What is Jev?

Jev is an AI model from TypeSafe AI. TypeSafe released it in September 2026. They call it a System One model. The job is simple: look at information, then make a decision your software can use.

Think of it like a smart if else.

In a store, you can write this in normal code: if an order has more than three items, show an offer. That rule is clear. You do not need AI.

Now look at the customer message again.

Customer message

I have contacted you three times, and I am still waiting.

You could hunt for words like “waiting” or “three times.” That is brittle. A polite complaint and a joke can use the same words. Jev reads the text and returns a structured decision, not a paragraph.

What does System One mean?

The name comes from the book Thinking, Fast and Slow by Daniel Kahneman. System 1 is fast judgment. System 2 is slow, careful thinking. TypeSafe built Jev for the fast kind of call your app has to make again and again.

The name Jev points to Jevons Paradox. William Stanley Jevons saw that better steam engines used less coal for the same work, but people then used far more coal overall. If a decision becomes cheap and fast, teams start putting that decision in more places.

Why use it?

You use Jev when your code needs a judgment, and you already know what a valid answer looks like.

TypeSafe says end to end response time is about 70ms to 500ms. That is fast enough to sit inside a live app, not only in a slow chat.

The other reason is structure. Jev does not write you a story. It returns values you defined: yes or no with a probability, one option from a list, or a score on your scale. Your n8n workflow or API can branch on that value right away.

TypeSafe also says every answer comes with a probability or confidence. That lets you set a rule: act only if the model is sure enough. If not, send it to a person.

Jev vs GPT and Claude

Yes, GPT and Claude can judge text too. They can also write a reply, explain a topic, summarize a page, and generate code.

Jev is not built for those other jobs. It gives up free text on purpose. TypeSafe trains it for calibrated decisions and typed outputs.

  • GPT and Claude: write, chat, plan, code, and also judge when you ask.
  • Jev: judge only. Fast. Cheap. Output is a value your code already expects.

TypeSafe says Jev can be about 40x to 200x faster than a frontier chat model on this kind of question. They also compare cost. Chat models often charge more for output tokens. Jev output tokens are free.

If you need a kind email back to the customer, use GPT or Claude. If you only need “frustrated: yes, probability 0.9,” Jev fits better.

How much does it cost?

TypeSafe lists input tokens at $0.042 per million. That is about $42 per billion input tokens. Output tokens are free.

Say you get 10,000 customer messages a day. Each call uses about 500 input tokens for the message plus your question. That is about 5 million input tokens a day. At this price, that is about 21 cents a day.

So the cost per decision can stay very low when the same judgment runs all day. Prices can change. Check TypeSafe before you plan a budget.

How does it work?

The flow is small:

State + Question → Structured answer

State is the information Jev looks at. It can be plain text, JSON, or a list. Example state: “I have contacted you three times, and I am still waiting.”

Then you ask a typed question. TypeSafe has three main types. They call the yes or no type Noul.

1. Noul

Yes or no You ask: is this customer frustrated? Jev returns a probability from 0 to 1. Near 1 means likely yes. Near 0 means likely no. Near 0.5 means unsure.

2. Choice

Pick from your list You ask why they wrote in. You give the options: update, refund, replacement, or something else. Jev picks one and can show a probability for each option.

3. Score

Rate on your scale You define the levels. 0 is no frustration. 1 is unhappy. 2 is strong anger. Jev returns a score on that scale.

You can send more than one question in the same request. Jev can score them in parallel against the same state.

What the response looks like

  • Noul: the yes chance, as a number from 0 to 1.
  • Choice: the winning option, plus probabilities for the other options.
  • Score: the score, probabilities, and the levels you defined.

A Jev answer is not always right. Set a threshold. Example: auto route only if the Noul value is above 0.85. Below that, a human reviews it.

The response can also include token use, so you can track cost.

How do you get started?

TypeSafe opened Jev in early access. You start at typesafe.ai. You do not need a chat window. You send a request from your app or from n8n.

  1. Write one real judgment you already make by hand.
  2. Name the state. Name the question. Pick Noul, Choice, or Score.
  3. Write the options or the scale yourself. Do not let the model invent labels.
  4. Call the TypeSafe API with that state and those questions.
  5. Set a confidence rule before the workflow takes an action.

A first Choice question can look like this:

{
  "state": "I have contacted you three times, and I am still waiting.",
  "questions": {
    "reason": {
      "type": "choice",
      "instructions": "Why is this customer contacting us?",
      "criteria": {
        "update": "Asking for an update",
        "refund": "Requesting a refund",
        "replacement": "Requesting a replacement",
        "other": "Something else"
      }
    }
  }
}

Keep secrets out of the state. Do not send API keys or .env values. Jev will judge whatever you put in the state, so send only what the decision needs.

When to use it, and when to skip it

Jev can help when you need to:

  • Route a customer request
  • Sort a document into a known set of labels
  • Check if a passage supports a claim
  • Pick which bigger model should handle the next step
  • Make a quick in-app or game choice
  • Guard an LLM output before you show it or run it

Do not use Jev when you need to:

  • Write a reply
  • Summarize an article
  • Generate code

Those jobs need a model that writes text. Also skip AI when normal code is enough. If you only need to check that a basket has three items, write an if statement.

Ask three questions before you add Jev:

  1. Is there a judgment to make?
  2. Can you name the possible answers?
  3. Does speed, cost, or high volume matter?

If all three are yes, Jev is worth a test.

Final summary

Jev decides. It does not write.

  • State plus a typed question gives a structured answer.
  • Noul is yes or no. Choice picks from your list. Score uses your scale.
  • TypeSafe prices input low and output at zero. Speed is in the milliseconds.
  • Use GPT or Claude when you need prose. Use code when the rule is already exact.
  • Never trust one score blindly. Set a threshold. Send weak cases to a person.
